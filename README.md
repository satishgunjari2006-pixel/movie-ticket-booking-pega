# Movie Ticket Booking Management Application

A Movie Ticket Booking Management Application developed using **Pega Platform** as part of the **SkillWallet National Internship Program**.

## Project Overview

The application helps CineWave Entertainment manage movie ticket booking requests through a structured Pega case lifecycle. It allows customer booking details to be captured, checks show availability, calculates booking cost, confirms the booking, processes the ticket, and provides final booking confirmation.

## Case Lifecycle

The **Movie Ticket Request** case type contains the following stages:

1. **Create**
   - Enter Booking Details

2. **Check Show Availability**
   - Check Show Details

3. **Calculate Cost**
   - Calculate Cost

4. **Confirm Booking**
   - Confirm Booking Request

5. **Process Booking**
   - Review Booking Details
   - Complete Booking

6. **Confirmation**
   - Booking Confirmation

## Data Model

The application captures information such as:

- Customer Name
- Email
- Phone Number
- Movie Name
- Theatre Name
- City
- State
- Show Date
- Show Time
- Number of Seats
- Seat Numbers
- Seats Available
- Ticket Price
- Total Cost
- Booking Confirmation
- Booking Reference
- Booking Status
- Notification Status

## Features

- Submit movie ticket booking requests
- Check movie show and seat availability
- Calculate ticket booking cost
- Capture customer booking confirmation
- Review booking information
- Process and complete ticket booking
- Generate a booking reference
- Track booking status
- Confirm customer notification
- Complete the case with Resolved-Completed status
